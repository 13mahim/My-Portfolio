A modern, animated personal portfolio built with React, TypeScript, and Framer Motion.

---

## Features

- Smooth animations powered by Framer Motion
- Fully responsive - mobile, tablet, desktop
- Dark glassmorphism UI with purple gradient accents
- Sections: Hero, Projects, Skills, Education, Training, Contact

## Tech Stack

- Frontend: React 19, TypeScript, Tailwind CSS v4
- Animation: Framer Motion
- Icons: Lucide React
- Build Tool: Vite 6

## Getting Started

Prerequisites: Node.js 18+

    git clone https://github.com/13mahim/My-Portfolio.git
    cd My-Portfolio
    npm install
    npm run dev

App runs at http://localhost:3000
